## Agent skills

### Issue tracker

Los problemas (issues) se administran a través de GitHub Issues. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Usamos las etiquetas por defecto (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). Ver `docs/agents/triage-labels.md`.

### Domain docs

Diseño de contexto único (un archivo `CONTEXT.md` en la raíz). Ver `docs/agents/domain.md`.
